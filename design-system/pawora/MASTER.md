# Pawora Design System

Nguồn ưu tiên: `DESIGN.md` → tài liệu này → page overrides.

## Direction

Photography-first premium pet commerce. Full-bleed editorial sections alternate white, parchment and near-black. UI chrome stays quiet; controls use Pawora Blue exclusively.

## Core tokens

- Primary: `#0066CC`; primary hover/focus: `#0071E3`; on-dark link: `#2997FF`.
- Ink: `#1D1D1F`; muted: `#66666B`; canvas: `#FFFFFF`; parchment: `#F5F5F7`.
- Base body: 17px, line-height 1.47; headings weight 600 and tight tracking.
- Spacing: 4, 8, 12, 16, 24, 32, 48, 80px.
- Radius: 8px utility, 18px cards, full pill actions.
- Touch target: at least 44×44px.

## Non-negotiables

- WCAG 2.2 AA contrast, visible focus, keyboard access, semantic labels.
- No emoji icons, decorative gradients, random radii or card shadows.
- Reserve image dimensions; lazy-load below-fold assets; reduced-motion fallback.
- Form errors stay inline and explain recovery.
